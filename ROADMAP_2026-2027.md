## 📅 ROADMAP DÉTAILLÉE

### **SPRINT 1-2 : SEPTEMBRE 2026 - Fondations & Quick Wins**

**Goal:** Atteindre feature parity avec Strong sur les essentiels, corriger les bugs UX

#### Must-Have (P0)

- [ ] **Plate Calculator** (5 days)
  - Input: exercice, poids désiré
  - Output: assiettes optimales (différentes plaques disponibles)
  - UI: modal rapide + saved presets
  - Value: ~50% des utilisateurs utilisent ça quotidiennement
- [ ] **1RM Calculator** (3 days)
  - Méthodes: Epley, Brzycki, Lander
  - Input: poids + reps effectués
  - Affiche l'historique 1RM par exercice
- [ ] **RPE Input UI** (2 days)
  - Ajoute champ RPE (1-10) dans live workout
  - Save en base de données
  - Backend déjà supporté
- [ ] **Fix French Hardcoded Strings** (2 days)
  - Remplacer les 25+ strings identifiées
  - Tester EN/FR mode
  - QA complet

- [ ] **Dashboard Sidebar Sticky** (1 day)
  - CSS fix pour position: sticky
  - Test sur desktop/tablet

#### High-Value (P1)

- [ ] **Workout Comparison** (3 days)
  - Compare 2 workouts: "Last week vs This week"
  - Show: volume delta, exercise changes, PR detection
  - UI: side-by-side chart

- [ ] **PDF Export** (4 days)
  - Convert existing CSV export to PDF
  - Template: clean printable format
  - Include: exercises, sets, reps, weight

#### Quality/Polish

- [ ] Audio/haptic feedback on set complete (mobile)
- [ ] Keyboard shortcuts for live workout (numpad)
- [ ] Confirm before exit on unsaved workouts
- [ ] Loading skeletons for async data

**Effort:** ~30 eng days | **Team:** 1 full-stack engineer

**Success Metrics:**

- 0 French text visible in workout pages
- 100% feature parity on calculators vs Strong
- Workout comparison used 30%+ of power users

### **SPRINT 3-4 : OCTOBRE 2026 - Coach Super-Powers**

**Goal:** Coach dashboard become "THE" place to manage athletes (vs Strong's basic approach)

#### Coach Space Enhancements (P1)

- [ ] **Real-Time Coach Updates** (5 days)
  - WebSocket listener: when athlete logs workout → coach sees live
  - Push notification to coach mobile
  - Coach feed updates in real-time (no refresh needed)
  - Backend: expand `/api/coaching/clients/:id` endpoint

- [ ] **Coach Messaging System** (6 days)
  - In-app 1-on-1 messaging: coach ↔ athlete
  - Backend: new `/api/coaching/messages` endpoints
  - Frontend: message thread view in client detail page
  - Mobile push notifications
  - Value: Coaches can give quick feedback without leaving Athletiq

- [ ] **Recovery/Fatigue Tracking** (7 days)
  - New page: `/body/recovery` (next to body stats)
  - Input: daily recovery score (1-10), sleep hours, soreness
  - Coach sees: fatigue trends per athlete
  - Coach can adjust workouts based on recovery data
  - Database: new `recovery` table + `athlete_recovery` junction

- [ ] **Performance Scoring Dashboard** (4 days)
  - Improve existing "Performance Pulse" with more metrics
  - Add: strength ratio tracking (squat:deadlift, bench:squat)
  - Show: trend lines for key metrics per athlete
  - Watchlist auto-updates based on score changes

#### Athlete-Side (P1)

- [ ] **Auto-Warmup Set Generator** (2 days)
  - Suggest warmup sets based on working weight
  - RPE-based warmup profiles
  - User can save preferred warmup scheme

- [ ] **Auto-Rest Timer** (1 day)
  - Predict rest based on RPE × volume
  - Suggest "ready?" when time is up
  - Customizable per user preference

**Effort:** ~30 eng days | **Team:** 2 engineers (1 backend, 1 frontend)

**Success Metrics:**

- 80%+ of coaches use real-time feed daily
- Recovery tracking adoption 40%+ in coach + athlete
- Messaging feature adoption 60%+ coaches
- Coach retention +15%

### **SPRINT 7-8 : JANUARY-FEBRUARY 2027 - AI & Predictions**

**Goal:** Introduce AI-powered coaching (leapfrog competitors entirely)

#### Predictive Analytics (P2)

- [ ] **Expected PR Prediction** (6 days)
  - ML model: predict when athlete will hit 1RM based on progression
  - Use methods: Epley, Brzycki, Lander, linear regression
  - Show: "You could hit 225lbs in 3 weeks if you maintain volume"
  - Update weekly based on new data
  - Backend: new `expected_pr` table + model inference

- [ ] **Injury Risk Scoring** (5 days)
  - ML model: detect sudden form regression, volume spikes, fatigue
  - Show: risk score per athlete
  - Alert coach: "John has 70% injury risk this week — suggest deload"
  - Backend integration with recovery data

#### AI Coaching Recommendations (P2)

- [ ] **Automated Coach Suggestions** (7 days)
  - For each athlete, generate weekly recommendations
  - Examples:
    - "Squat volume down 15% — increase intensity"
    - "Upper back lagging — add 2 sets of rows"
    - "Fatigue high, recovery low — take rest day"
    - "PR alert: New deadlift max!"
  - Generate via LLM (OpenAI/Claude API) or custom model
  - Coach can approve/ignore suggestions
  - Athlete can see: "Coach recommended deload week"

#### Workout Recommendation Engine (P2)

- [ ] **Auto-Program Generator** (3 days)
  - Coach selects: athlete goals, weekly frequency, focus areas
  - System generates personalized program
  - Considers: injury history, lift ratios, recovery status
  - Can be tweaked/customized by coach
  - Saves coach programming time by 50%

**Effort:** ~35 eng days | **Team:** 2 engineers + 1 ML engineer (or outsource model)

**Success Metrics:**

- 70%+ of coaches use AI recommendations at least weekly
- Athlete adherence +10% with personalized programs
- PR prediction accuracy 80%+ within 4-week window
- Injury alerts prevent 5+ injuries (survey-based)

**Goal:** Connect to Apple Watch, Garmin, WHOOP; introduce premium coaching tier

- [ ] **Apple Watch OAuth Integration** (5 days)

  - Show: HRV (Heart Rate Variability) trend

  - Fetch training load, VO2 max, stress levels

- [ ] **Billing & Coach Plans** (10 days)
  - Coach Free: 5 athletes
  - Coach Pro: unlimited athletes + all features
  - Team Plan: multiple coaches, shared analytics
  - Stripe integration

**Success Metrics:**
